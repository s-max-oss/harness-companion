# DSH acceptance package — 2.0.0 (2026-10-27)

This package replaces the retired Codex real-Agent evaluation as the release
gate for the DSH-only skill. It is reproducible, bounded, and recorded as
machine-readable evidence.

## Scope

- Repository: `s-max-oss/harness-companion`, branch
  `rc3-guided-conversational-init`.
- Host: DeepSeek Harness (DSH). Claude Code and Codex are out of scope; both
  CLIs remain usable as tools without this skill.
- Entry point under test: the skill's real launcher, `dsh/run.ps1`, invoked the
  same way a DSH session invokes it.

The same entry point was exercised interactively during the 2026-10-27 DSH
session that produced this release: repository status, feature transitions,

## What this package does not cover

- No automatic lifecycle hooks: DSH exposes none for skills. Status checks and
  handoff reminders rely on the explicit contract in `SKILL.md`.
- `audit` is slow on large run-log histories and is bounded by the caller's
  timeout, not by this package.
- The full repository suite (`tests/run-all.sh`) is a separate gate recorded in
  the changelog; this package covers acceptance, not regressions.
- The Codex-based forward evaluation (`F-CONV-08`) and its acceptance package
  (`F-CONV-09`) are deprecated because their subject pipeline was retired with
  the host adapters.

## Reproduce

```powershell
./dsh/acceptance.ps1
```

Exit 0 means every scenario passed and new evidence was written under
`tests/acceptance/evidence/<UTC timestamp>/`.
